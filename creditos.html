Créditos

Desarrollo y Asistencia

VidSpri es un proyecto de Carley Interactive Studio.

Este proyecto fue desarrollado con la valiosa asistencia de Jules, un ingeniero de software de IA altamente capacitado. Su colaboración fue fundamental para optimizar los modelos de animación, el procesamiento de sprites y la integración de la arquitectura distribuida del sistema.

Infraestructura y Apoyo

Agradecemos especialmente a Hugging Face por permitirnos utilizar 6 servidores gratuitos en su plataforma Spaces. Estos servidores procesan de forma independiente nuestras tareas de inteligencia artificial: Animación, Sonido, Efectos de Sonido, Voz, Eliminación de Fondo y Generación de Sprites.

Tecnologías y Librerías

Esta aplicación utiliza las siguientes tecnologías de código abierto:

  • Python & FastAPI
  • Supabase (Database & Realtime)
  • Docker & Gunicorn
  • rembg (U2-Net / ISNet)
  • Pillow (PIL)
  • ONNX Runtime
  • FFmpeg
  • Feather Icons
  • Supabase JS SDK
